# Easter-egg music

Drop your audio files here and list them in `TRACKS` in
`components/MusicEasterEgg.tsx`. Clicking the "Músico" badge cycles through them.

Default expected names:

- `track-1.mp3`
- `track-2.mp3`

## Use only music you're allowed to host

These files get committed and **deployed publicly**, so use royalty-free /
Creative Commons tracks (not commercial copyrighted songs). Good sources:

- **Pixabay Music** — pixabay.com/music (Pixabay license: free for commercial
  use, no attribution required — easiest option)
- **YouTube Audio Library** — studio.youtube.com (some tracks require credit)
- **Uppbeat** — uppbeat.io (free tier requires a credit)
- **Free Music Archive** — freemusicarchive.org (check each track's CC license)

Always check the specific track's license on its page — terms vary and change.
